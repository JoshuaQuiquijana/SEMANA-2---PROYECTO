Cuatro casos, un mismo rigor numérico

Simulador educativo inspirado en un sistema de transporte por cable. Cada caso se estudia con tres escenarios: normal, estrés y mal condicionado. Los datos son sintéticos.

Cada módulo permite ejecutar los tres escenarios (normal, estrés y mal condicionado), consultar tablas, errores y gráficos, y guardar el experimento en el historial.

Detención de emergencia de cabinas

Pregunta: ¿cómo varían el tiempo y la distancia de detención ante cambios de velocidad, reacción y frenado?

Modelo

v(t) = v₀ − a·t · · x(t) = x₀ + v₀·t − (a/2)·t²
t_det = v₀/a · · d_frenado = v₀²/(2a)

Se comparan RK2 y RK4 sobre la EDO de posición/velocidad e integración de v(t) con trapecio, Simpson 1/3 y Romberg.

Escenarios

Normalv₀=12 m/s, a=1,5 m/s², tᵣ=1 s, h=0,1.
Estrésv₀=18 m/s, a=1,0 m/s², tᵣ=1,5 s, h=0,25.
Mal condicionadoa cercana a 0 (a=0,05 m/s²) con alta sensibilidad en t_det.

Deterioro mecánico y mantenimiento

Pregunta: ¿cuándo alcanzaría un indicador hipotético de deterioro un umbral de inspección?

Modelo

D(t) = D₀ + αt + βt²
D(t) − D_umbral = 0

Los coeficientes se calibran con sistemas lineales SPD y se busca la raíz con bisección, Newton-Raphson y secante.

Métodos integrados

Jacobi, Gauss-Seidel, LU con pivoteo, gradiente conjugado y Cholesky; además de bisección, Newton-Raphson y secante para D(t) − D_umbral = 0.

Laboratorio de sistemas lineales

Se fija la solución exacta x* = (1, 2, …, n) y se calcula b = A x*. Así el error real de cada método es medible.

Oscilaciones por viento

Pregunta: ¿cómo cambia la oscilación ante cambios de fuerza, amortiguamiento y parámetros?

Modelo

x′ = v · · v′ = [F(t) − c·v − k·x] / m
ω₀ = √(k/m) · · ζ = c / (2√(mk))

Se resuelven las EDO con RK2 y RK4 y se integra x(t)² con trapecio, Simpson 1/3 y Romberg.

Escenarios

NormalVibración libre subamortiguada (0 < ζ < 1), h=0,05.
EstrésFuerza externa intensa y amortiguamiento reducido, h=0,1.
Mal condicionadoAmortiguamiento casi nulo (c=5) con alta sensibilidad de amplitud.

Reconstrucción de señales de sensores

Pregunta: ¿cómo reconstruir registros faltantes y medir la distorsión del ruido?

Modelo

y(t) = sin(t) o y(t) = e^(−t)
RMSE = √[(1/n) Σ (yᵢ − ŷᵢ)²]

Se ocultan puntos de prueba para evaluar Lagrange, Newton por diferencias divididas y splines cúbicos.

Escenarios

NormalSeñal limpia, 8 nodos equiespaciados, η=0.
EstrésRuido sintético (η=0,05) y menos nodos.
Mal condicionado16 nodos equiespaciados en intervalo amplio: oscilación tipo Runge en polinomios globales.
